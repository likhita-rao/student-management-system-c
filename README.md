
# Student Management System in C

A menu-driven Student Management System built in C using structures, arrays, functions, pointers, and string handling.

## Features

- Add student records
- Display student records
- Search for a student
- Update student information
- Delete student records

## Concepts Used

- Structures
- Arrays
- Functions
- Pointers
- String handling
- Conditional statements and loops

## How to Run

1. Download `student_management.c`
2. Compile the program using a C compiler.
3. Run the executable.
